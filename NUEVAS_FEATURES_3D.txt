1. ✅ ENEMIGOS 3D CON SOMBRAS
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   
   ¡LOS ENEMIGOS YA NO SON PLANOS!
   
   🎨 EFECTO 3D CON SOMBRAS:
   • Cálculo de shadeFactor basado en posición
   • Partes centrales más brillantes
   • Partes laterales más oscuras
   • Sensación de volumen y profundidad
   
   👤 SOLDADOS (Estilo 3D detallado):
   • Piernas (gris oscuro)
   • Torso (uniforme gris con sombras)
   • Brazos visibles a los lados
   • Cabeza (color piel realista)
   • Casco verde oscuro
   • Banda roja nazi en el pecho
   • ¡Parecen figuras 3D reales!
   
   🐕 PERROS (Diseño único):
   • Más bajos que los soldados (60% altura)
   • Cuerpo marrón robusto
   • Cabeza prominente adelante
   • Patas animadas
   • OJOS ROJOS brillantes (¡agresivos!)
   • Postura de ataque
   
   RESULTADO: ¡Enemigos con volumen y profundidad! 🎨

2. ✅ PERROS ATACANTES
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   
   🐕💨 PERROS GUARDIANES NAZIS:
   
   CARACTERÍSTICAS:
   • ¡CORREN AL DOBLE DE VELOCIDAD! (0.6 vs 0.3)
   • Actualización cada 0.2s (vs 0.5s soldados)
   • Rango de detección: 25 unidades
   • Atacan de cerca (< 1.0 unidad)
   • Daño por ataque: 8 HP
   • ¡TE PERSIGUEN IMPLACABLEMENTE!
   
   ESTRATEGIA IA:
   • Corren directo hacia el jugador
   • No disparan, solo atacan cuerpo a cuerpo
   • Más agresivos y peligrosos de cerca
   • Perfectos para emboscadas
   
   DISTRIBUCIÓN:
   • 7 Soldados + 7 Perros = 14 enemigos
   • Alternados por el mapa
   • ¡Variedad de amenazas!

3. ✅ SOLDADOS DISPARAN BALAS
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   
   🔫 SISTEMA DE DISPARO ENEMIGO:
   
   MECÁNICA:
   • Soldados mantienen distancia (3-15 unidades)
   • Disparan cada 2-3 segundos (cooldown variable)
   • Solo disparan si estás en rango
   • Retroceden si te acercas demasiado
   • ¡BALAS FÍSICAS que viajan por el espacio!
   
   IA TÁCTICA:
   • Acercarse si dist > 3.0
   • Retroceder si dist < 2.0
   • Disparar si 2.0 < dist < 15.0
   • Movimiento más lento que perros (0.25)
   
   DAÑO:
   • Bala enemiga: 15 HP
   • ¡Peligroso a distancia!

4. ✅ BALAS ENEMIGAS VISIBLES
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   
   🔴 ¡VES LAS BALAS VINIENDO HACIA TI!
   
   APARIENCIA:
   • COLOR: Rojo brillante (255, 0, 0)
   • BORDE: Naranja brillante (255, 150, 0)
   • ESTELA: Aura roja detrás
   • TAMAÑO: Más grandes que balas jugador
   • ¡MUY VISIBLE Y AMENAZANTE!
   
   FÍSICA:
   • Velocidad: 0.3 (más lento que jugador)
   • Lifetime: 120 frames (2 segundos)
   • Colisión con paredes
   • Colisión con jugador (radio 0.5)
   • Z-buffer: No se ven detrás de paredes
   
   EFECTO VISUAL:
   • Núcleo rojo sólido
   • Borde naranja brillante
   • Estela roja expandida
   • ¡Perfectamente visible mientras vuela!
   
   RESULTADO: ¡Puedes esquivar las balas! 🎯

5. ✅ TEXTURA DE CIELO EN EL TECHO
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   
   ☁️ CIELO PROCEDURAL REALISTA:
   
   GRADIENTE:
   • Arriba: Azul claro (235, 206, 135)
   • Abajo: Azul más oscuro
   • Transición suave
   • Sensación de atmósfera
   
   NUBES:
   • Patrón procedural matemático
   • Blancas (255, 255, 255)
   • Distribuidas naturalmente
   • En el tercio superior del cielo
   
   ALGORITMO:
   • cloudPattern = ((x / 40 + y / 30) % 5) + ((x / 20) % 3)
   • if cloudPattern > 5 → Nube
   • else → Cielo azul
   
   RESULTADO: ¡Techo realista como cielo abierto! ☀️

ALGORITMO DE SOMBRAS 3D:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

int relativeX = stripe - drawStartX;
int spriteCenter = spriteWidth / 2;
int distFromCenter = abs(relativeX - spriteCenter);
float shadeFactor = 1.0 - (distFromCenter / (float)spriteCenter) * 0.3;

// Aplicar shadeFactor a cada color:
color * shadeFactor

RESULTADO: Centro brillante, bordes oscuros → Efecto 3D

IA DE SOLDADOS (con disparo):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

enemy.shootTimer += deltaTime;

if(enemy.shootTimer > enemy.shootCooldown && dist < 15 && dist > 2.0) {
    // Crear bala enemiga
    Bullet enemyBullet;
    enemyBullet.x = enemy.x;
    enemyBullet.y = enemy.y;
    enemyBullet.dirX = dx / dist;  // Hacia jugador
    enemyBullet.dirY = dy / dist;
    enemyBullet.lifetime = 120;
    enemyBullet.active = true;
    enemyBullet.isEnemy = true;
    enemyBullets.push_back(enemyBullet);
}
