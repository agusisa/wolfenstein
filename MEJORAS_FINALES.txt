1. ✅ Z-BUFFER PARA PROFUNDIDAD
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   
   ¡PROBLEMA SOLUCIONADO!
   • Las balas YA NO se ven detrás de las paredes
   • Los enemigos YA NO se ven detrás de las paredes
   • Los items YA NO se ven detrás de las paredes
   
   IMPLEMENTACIÓN:
   • Array zBuffer[SCREEN_WIDTH] para almacenar distancias
   • Durante el raycasting se guarda la distancia de cada columna
   • Antes de dibujar sprites, se compara su distancia con el z-buffer
   • Si sprite.distance >= zBuffer[x], NO se dibuja
   
   RESULTADO: ¡Depth testing perfecto! 🎮
